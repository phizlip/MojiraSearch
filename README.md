# MojiraSearch

Semantic search and duplicate detection for [Mojira](https://bugs.mojang.com). Indexes bug reports as vector embeddings and lets you search by meaning rather than exact keywords.

## Stack

- **[nomic-embed-text-v1.5](https://huggingface.co/nomic-ai/nomic-embed-text-v1.5)**: local embedding model
- **[Qdrant](https://qdrant.tech)**: vector database for similarity search
- **SQLite**: crawl state, issue metadata, and resolution tracking
- **FastAPI**: search and status API

## Setup

Requires Python 3.10+ and Docker.

```sh
cp .env.example .env
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
docker compose up -d
python -m indexer.worker
uvicorn api.main:app --host 0.0.0.0 --port 8000
```

## Sync strategy

The indexer runs two passes per project on each cycle:

- **Delta sync**: queries Jira's public JQL endpoint for recently updated issues based on the last sync timestamp.
- **Forward sync**: crawls forward from the highest known key until hitting 15 consecutive 404s, bridging any gaps found during the delta sync. Keys confirmed as missing are cached for 48 hours to avoid redundant requests.

## Duplicate detection

Switch to Duplicate Check mode and enter an issue key (e.g. `MC-12345`). The frontend queries `/api/similar/{key}` and returns the closest matches. Please note that detection may not always be accurate, so always double check the results yourself.
